# AI Copywriter Assistant — Лендинг

 📌 Описание
Учебный проект — посадочная страница (landing page) для сервиса по генерации текстов с помощью искусственного интеллекта.

 🛠️ Использованные технологии
- HTML
- CSS (Flexbox, Grid, медиа-запросы)

 📱 Что умеет страница
- Адаптивная вёрстка (корректно отображается на телефонах и компьютерах)
- Интерактивные элементы (кнопки меняют цвет при наведении)
- Структура, готовая для добавления логики на JavaScript

 🚀 Как запустить
1. Скачать репозиторий
2. Открыть файл `index.html` в любом браузере
